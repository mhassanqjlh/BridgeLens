# BridgeLens

Advanced, cloud-native BridgeLens provides real-time data aggregation and auto-scaling capabilities through a unified gateway.

BridgeLens is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/BridgeLens.git`
2. `cd BridgeLens`
3. Install in editable mode: `pip install -e .`

## Configuration

BridgeLens is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
